# Commandes FTB Quests

Retour : [[FTB Quests - Vue d'ensemble]]
`<>` = obligatoire, `[]` = optionnel

| Commande | Effet |
|---|---|
| `/ftbquests open_book [questId]` | ouvre le livre, éventuellement sur une quête |
| `/ftbquests editing_mode [true\|false] [player]` | active ou désactive le mode édition |
| `/ftbquests change_progress <player> <reset\|complete> <questId>` | modifie la progression d'une quête |
| `/ftbquests change_progress <player> <reset-all\|complete-all>` | réinitialise ou complète tout |
| `/ftbquests block_rewards [true\|false] [player]` | empêche de réclamer |
| `/ftbquests locked [true\|false] [player]` | verrouille le livre |
| `/ftbquests reload` | recharge la config et les quêtes |
| `/ftbquests import_reward_table_from_chest <nom> <pos>` | coffre → table |
| `/ftbquests export_reward_table_to_chest <rewardId> <pos>` | table → coffre |
| `/ftbquests delete_empty_reward_tables` | nettoyage |
| `/ftbquests generate_chapter_with_all_items_in_game` | debug |
| `/ftbquests clear_item_display_cache` | cache client |
