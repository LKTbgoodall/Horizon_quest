# 2026-11-14

## Launcher 0.2.65: horizon#15933 still not fixed
- Bastien: a new launcher update is out, is it good? `horizon-launcher --version` = 0.2.65; `versions`: the newest Nightly is still `nightly-2026-11-13-9f42064` (our pin).
- PR horizon-rust/horizon#16007 (the fix for #15933, a combined `.hmod`'s content never reaching `native-content/`) and the issue are **still open** (GitHub API). `launcher/src/native_mods.rs` at `launcher@0.2.65` (`ec85e81`) still copies each bundle with `copy_bundle(b, &incoming.join(&b.id))`, without the PR's `copy_for_build`. So a `-Combined` build still installs the code without the textures: 1.0.0 keeps waiting.
- Noted for plan B ([[ADR-015 Embed the content pack in the native mod]]): at `9f42064` the content loading is `content_root_at(root, enabled, disabled, dev, here, version)`, not the `content_root(root, enabled, dev)` AE2 hooks at `fdc87ae`; plan B would have to be checked against it.
- Pitfall again: a Python edit given `tools\build-mod.ps1` in a normal string read `\b` as a backspace and failed; use raw strings.
