## ✅ Done
- GitHub releases checked again: **the `nightly` release is still `9f42064`** (2026-11-13, assets untouched), and no `sdk-<commit>` release exists. Nothing to pin yet.
- Read horizon-rust/horizon#18051 (`1c4b79b`, merged 2026-11-17 22:06 UTC; `docs/release-flow.md`, `docs/modding/src/reference/sdk/01-release.md`):
  - Each Nightly is now built together with the signed SDK of its exact commit: `prebuilt-game-build.yml` builds it on four legs (Linux client and server, Windows GNU client, macOS ARM64 client), `sdk-publish.yml` signs it and creates the immutable prerelease **`sdk-<sha>`**, and the Nightly release gets its `sdk.json`. The launcher reads the build id from the Nightly and builds native mods against `sdk-<sha>`.
  - A build without its `sdk-<sha>` release cannot build native mods; the launcher never rebuilds the game to fill the gap. A Nightly predating this route (like `9f42064`) has no SDK.
  - **Nightlies are built only by hand since 2026-11-15** (`nightly-build.yml`: `release.yml`, `/nightly` or a dispatch; no schedule). So the next one comes when a maintainer starts it, not on a daily clock.
