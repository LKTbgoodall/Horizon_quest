## 🧠 Learned / found
- **"Fitting another build"** (Horizon docs `reference/sdk/04-fit.md`): a native mod on the mod API alone can now be compiled against a newer build than the one it pins, when nothing it uses changed, judged from the package's `uses.json` (written by `cargo horizon-mod build`). Without one, a mod works only on its own build. We build from the source folder, so we keep re-pinning on each Nightly for now.
- The SDK's `api-source.tar.xz` holds the API crate's lock only (39 packages); the game's full graph is the Horizon workspace `Cargo.lock` at the commit.
- Launcher: a native build prepares its base version itself (#18664), Build waits for a busy native cache (#19303), a native mod may enable features of a crate the game also locks (#18526).
- Shell pitfall: backslashes in a Python heredoc sent through the Bash tool came out halved; use `chr(92)` in such scripts.
