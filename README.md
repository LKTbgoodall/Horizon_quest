# Horizon Quest

A quest book mod for [Horizon](https://playhorizon.dev), the Rust rewrite of Minecraft: Java Edition 26.3. It takes its ideas from FTB Quests: chapters, quests linked by dependencies, tasks, rewards, and progress shared by a team.

> Status: early planning. No code yet.

- Project docs and design are in [`vault/`](vault/00%20-%20Accueil.md), an Obsidian vault written in French.
- The mod is written from scratch as a Horizon native mod in Rust. It contains no FTB Quests code or assets.
